A quick look

function soma(a: int, b: int) -> int {
    return a + b
}

enum Direction { North, East, South, West }

struct Point {
    x: int,
    y: int
}

let p: Point = Point { x: 1, y: 2 }
print(soma(p.x, p.y))

for i in 0..3 {
    print(i)
}

Getting started

spg --version
echo 'print("hello, world")' > hello.spg
spg hello.spg

Add #> friendly-terminal at the top of a file to get friendlier error messages.

All previous versions are on the releases page.
