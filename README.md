# Spaghetti downloads

Installers and packages for every release of the Spaghetti language.

- **Windows:** download `spaghetti-X.Y.Z-windows-setup.exe` and follow the installer.
- **Linux:** download `spaghetti-X.Y.Z-linux.tar.gz`, extract it, and run `./spaghetti/install.sh`.

The source code is private. This repository only distributes releases.
